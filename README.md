# Top Reads Mk2

Top Reads Mk2 is a JavaFX book discovery application created for MAC 190. The app lets users browse a book catalog, search books by genre, view book details, and open selected books for online reading.

## Features

- Browse the full book catalog
- Search books by genre
- View book details including title, author, genre, description, and rating
- Open a selected book in an embedded web view
- Loads book data from a CSV file
- Uses object-oriented Java concepts such as abstraction, inheritance, interfaces, and encapsulation
